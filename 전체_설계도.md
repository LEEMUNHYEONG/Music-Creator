# Music Creator - 전체 설계도

> AI 기반 가사 제작 & 수노(Suno) 프롬프트 & 마케팅 자료 생성기  
> 최종 작성: 프로그램 구조 분석 기반

---

## 1. 프로그램 개요

| 항목     | 내용                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------ |
| **목적** | 가사 작성 → 수노 AI용 변환 → AI 분석 → 개선안 적용 → 최종 출력 → 마케팅 자료 생성까지 한 흐름으로 지원 |
| **대상** | Suno AI 등 음악 생성 서비스 사용자, 작사·마케팅 담당자                                                 |
| **실행** | 단일 페이지 웹 앱(SPA). `index.html` + `app.js` + `styles.css` 로 브라우저에서 실행                    |

## 4. 데이터 모델

### 4.1 프로젝트 객체 (한 곡 = 한 프로젝트)

```javascript
{
  id: string,              // 예: "proj_1733123456789_abc123def"
  title: string,           // 곡 제목 (1/2/5단계 제목 중 하나)
  savedAt: string,        // ISO 날짜
  updatedAt: string,
  createdAt: string,
  lastStep: number,       // 1~6, 마지막 진행 단계
  data: {
    // ─── 1단계 ───
    originalLyrics: string,
    manualStylePrompt: string,
    step1Tags: { genre, mood, era, theme, perspective, time, special, region },
    // ─── 2단계 ───
    sunoLyrics: string,
    stylePrompt: string,
    step2Tags: { audioFormat, venue, vocalStyle, instruments },
    tempo: string,
    vocalPartAssignments: { [파트명]: "보컬 스타일" },
    // ─── 3단계 ───
    analysis: { raw, scores, feedbacks, ... },  // Gemini 분석 결과
    feedbacks: array,
    // ─── 4단계 ───
    finalizedLyrics: string,
    finalizedStyle: string,
    // ─── 5단계 ───
    finalLyrics: string,
    finalStyle: string,
    // ─── 6단계 ───
    marketing: {
      youtubeDesc: string,
      tiktokDesc: string,
      hashtags: string,
      thumbnails: string[],
      mvSettings: { era, country, location, characterCount, ... },
      mvScenes: [ { location, mood, lighting, ... }, ... ]
    }
  }
}
```

### 4.2 localStorage 키

| 키                       | 용도                                         |
| ------------------------ | -------------------------------------------- |
| `musicCreatorProjects`   | 메인 프로젝트 목록 (우선 사용)               |
| `savedProjects`          | 저장된 프로젝트 (호환용)                     |
| `sunoLyricsHistory`      | 수노 가사 이력 (프로젝트와 별도)             |
| `stylePromptHistory`     | 스타일 프롬프트 이력                         |
| `musicCreatorGuidelines` | 뮤직모리 제작 지침서 (전역, 프로젝트별 아님) |
| `openai_api_key`         | OpenAI API 키 (설정 모달에서 저장)           |

- 프로젝트 로드 시 위 키들을 **우선순위대로** 참고하여, 동일 ID면 가장 완전한 데이터를 골라 병합·복원함.

## 5. 6단계 워크플로우

```text
[1단계: 가사 작성] → [2단계: 수노 변환] → [3단계: AI 분석] → [4단계: 개선안] → [5단계: 최종 출력] → [6단계: 마케팅]
```

| 단계  | 패널 ID | 주요 기능                        | 입력 → 출력                                                              |
| ----- | ------- | -------------------------------- | ------------------------------------------------------------------------ |
| **1** | panel1  | 직접 입력 또는 AI 가사 생성      | 제목, 가사, 스타일 프롬프트, 장르/분위기/테마 등 태그                    |
| **2** | panel2  | 수노용 가사·스타일 프롬프트 생성 | 1단계 가사+지침서 → 수노 가사, 스타일 프롬프트(음향/장소/보컬/악기/템포) |
| **3** | panel3  | Gemini 가사 분석                 | 2단계 가사 → 점수, 피드백, 개선 제안                                     |
| **4** | panel4  | 개선안 선택·적용                 | 3단계 피드백 → 선택 적용/전체 적용 → 확정 가사·스타일                    |
| **5** | panel5  | 최종 출력·평가                   | 확정 가사/스타일 표시, AI 최종 평가(개선 전/후 점수), 복사               |
| **6** | panel6  | 마케팅 자료 생성                 | 유튜브/틱톡 설명, 해시태그, 썸네일, MV 씬별 프롬프트(미드저니 등)        |

- **단계 순서**는 드래그로 변경 가능(progress-steps 내 `.step` 드래그).
- **진행 상태**는 `lastStep`과 단계별 완료 여부로 관리하며, 사이드바·상단 단계 뱃지에 반영됨.

## 6. UI 구조

### 6.1 전체 레이아웃

```text
┌──────────────────────────────────────────────────────────────────┐
│ [사이드바 토글]  [현재 곡 제목] [API 선택] [관리 메뉴] [수정] [테마] │  ← 헤더
├────────────┬───────────────────────────────────────────────────────┤
│            │  [1 가사] [2 수노] [3 분석] [4 개선] [5 출력] [6 마케팅] │  ← 단계 스텝
│  사이드바   ├───────────────────────────────────────────────────────┤
│  - 검색     │                                                       │
│  - 정렬     │              panel1 ~ panel6 (한 번에 하나만 active)     │
│  - 프로젝트  │                                                       │
│  목록       │                                                       │
│            │                                                       │
└────────────┴───────────────────────────────────────────────────────┘
```

### 6.2 사이드바 (id="sidebar")

- **기능**: 프로젝트 검색, 정렬(저장일/제목/진행단계), 프로젝트 목록 클릭 시 `loadProject(id)` 호출.
- **데이터**: `loadProjectList()`로 위 localStorage 키들에서 목록을 모아 표시.
- **드래그/리사이즈**: `initSidebarDrag`, `initSidebarResize` (app.js).
- **오버레이**: `sidebarOverlay` — 열린 사이드바 뒤 배경 클릭 시 닫기.

### 6.3 헤더

- **currentSongTitle / songTitleText**: 현재 프로젝트 제목.
- **apiSelector**: AI 선택(Dual AI 등).
- **adminMenuTrigger**: 관리자 메뉴(API 설정, 지침서, 참조, 백업, 복구, 저장 후 닫기 등).
- **editModeToggleBtn**: 수정 모드 ↔ 읽기 전용.
- **themeToggleBtn**: 다크/라이트 테마.

### 6.4 단계 스텝 (progress-steps)

- **요소**: `.step[data-step="1"]` ~ `data-step="6"` (가사 작성, 수노 변환, AI 분석, 개선안, 최종 출력, 마케팅).
- **클릭**: `goToStep(step, saveBefore, skipValidation)` 호출 → 해당 `panel`만 `.active`, 나머지 숨김.
- **완료 표시**: `.step-complete` 클래스로 체크 표시. `updateStepProgress()`에서 단계별 데이터 유무로 갱신.

### 6.5 패널 (panel1 ~ panel6)

- **공통**: `class="panel"`, `id="panel1"` ~ `panel6`. 하나만 `panel active`로 표시.
- **전환**: `goToStep(step)`에서 `panel${step}`만 active, 나머지 `display: none` 처리.
- **복원**: `restoreStepData(step)` — 로드된 `window.currentProject.data`를 해당 단계 DOM에 채움.

### 6.6 모달

| ID                    | 용도                                                                                                      |
| --------------------- | --------------------------------------------------------------------------------------------------------- |
| guidelinesModal       | 뮤직모리 제작 지침서 편집 (openGuidelinesModal / closeGuidelinesModal / saveGuidelines / resetGuidelines) |
| projectReferenceModal | 저장된 프로젝트에서 참조 (가사/스타일 참고)                                                               |
| apiSettingsModal      | OpenAI API 키 설정                                                                                        |
| stepOrderHelpModal    | 단계 순서 변경 안내                                                                                       |
| fileRecoveryModal     | 파일 복구 (백업/복구 플로우)                                                                              |

- **표시 제어**: `modal-overlay` + `.show` 클래스. `forceHideOverlays()`는 `show`가 있는 모달은 숨기지 않음.

## 7. 주요 함수·모듈 (app.js)

### 7.1 프로젝트·저장소

| 함수                            | 역할                                                                                                                      |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `loadProject(projectId)`        | localStorage에서 프로젝트 찾아 `window.currentProject`에 넣고, 1~6단계 DOM 복원 + `restoreStepData`, `updateStepProgress` |
| `saveCurrentProject()`          | 현재 DOM + `currentProject.data`를 반영해 프로젝트 객체 구성 후, `musicCreatorProjects` 등에 저장                         |
| `loadProjectList()`             | 프로젝트 목록을 가져와 사이드바에 렌더링, 정렬 옵션 적용                                                                  |
| `validateProjectData(project)`  | 프로젝트 필수 필드·타입 검사                                                                                              |
| `normalizeProjectData(project)` | 이전 형식 호환용 정규화                                                                                                   |

### 7.2 단계·UI 전환

| 함수                                                | 역할                                                                          |
| --------------------------------------------------- | ----------------------------------------------------------------------------- |
| `goToStep(step, saveBefore, skipValidation)`        | 단계 전환: 필요 시 저장 후, 해당 panel만 active, `restoreStepData(step)` 호출 |
| `restoreStepData(step)`                             | `currentProject.data`를 해당 단계의 input/textarea/태그 등에 복원             |
| `updateStepProgress()`                              | 각 단계별 데이터 유무로 `.step-complete` 갱신                                 |
| `goToNextStep()`                                    | 현재 단계에서 다음 단계로 이동                                                |
| `goToStep2To3()`, `goToStep4AndApplyImprovements()` | 2→3, 4→5 등 단계별 전용 이동/적용                                             |

### 7.3 수정 모드·읽기 전용

| 함수                        | 역할                                |
| --------------------------- | ----------------------------------- |
| `toggleEditMode()`          | `window.editMode` 토글 후 UI 갱신   |
| `updateEditModeUI()`        | 버튼 텍스트·입력 필드 readonly 반영 |
| `setReadOnlyMode(readonly)` | 입력 요소 일괄 readonly/해제        |

### 7.4 1단계 (가사 작성)

| 함수                                 | 역할                                                 |
| ------------------------------------ | ---------------------------------------------------- |
| `generateAILyrics()`                 | 지침서+옵션 기반으로 AI 가사 4개 생성 → 선택 UI 표시 |

### 7.5 2단계 (수노 변환)

| 함수                       | 역할                                                                 |

## 9. 이벤트·생명주기

- **DOMContentLoaded**: `loadProjectList()`, `initStepDragAndDrop()`, 사이드바/드래그 초기화 등.
- **beforeunload**: 변경 사항 있으면 자동 저장 시도(새 프로젝트로 저장할 수 있음).
- **forceHideOverlays()**: 스크립트 로드 시·DOMContentLoaded·setTimeout 다회 호출. `show` 클래스가 있는 모달은 건드리지 않음.
